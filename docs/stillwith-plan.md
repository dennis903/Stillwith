# Stillwith 기획서 v0.3

> 가칭이었던 "가상 학습 메이트"의 정식 앱 이름을 Stillwith(스틸위드)로 정했다.

> 작성일: 2026-11-18 · 상태: 초안 · 앱 이름: Stillwith
>
> **[가정]** 표시는 아직 확정되지 않아 임시로 채운 내용이다. 16장 "열린 질문"에 모아 두었다.
>
> 함께 보는 문서: `GLOSSARY.md`(용어집), `docs/adr/0001`(모든 기기에서 같은 장면), `docs/adr/0002`(Unity 한 벌). 이 문서의 굵은 용어는 용어집의 정의를 따른다.

## v0.2에서 바뀐 점

- **목표를 출시로 바꿨다.** v0.2의 "1차 목표는 본인 사용"을 버리고, 여러 기기의 다른 사람도 쓰도록 iOS와 안드로이드에 출시한다. 출시 준비가 다시 범위에 들어왔다.
- **모든 기기에서 같은 장면을 보여 준다.** 아이패드, 아이폰, 안드로이드 폰, 안드로이드 태블릿에서 가로와 세로를 모두 지원한다. 장면은 세 겹 영역으로 만든다. (ADR 0001)
- **웹앱을 버리고 Unity 6(URP) 한 벌로 만든다.** 조명 굽기도 Blender에서 Unity로 옮겼다. (ADR 0002)
- **캐릭터가 여러 명이 됐고, 판매 대상이 됐다.** 기본 캐릭터 3명에 추가 캐릭터를 판다. 모든 캐릭터는 사람형 뼈대 하나를 공유한다.
- **판매 구조를 정했다.** 무료로 받고, 추가 장소와 추가 캐릭터를 하나씩 일회 구매한다. 구독, 광고, 뽑기는 없다.
- **시간 계산 규칙을 정했다.** 함께한 시간, 보류 구간, 연속 시간, 세션, 하루의 정의와 경계 상황을 정했다.
- **용어를 정리했다.** '자리'와 '쉬기'를 두 가지 뜻으로 쓰던 것을 착석/이탈, 집중 지점/쉼 지점, 휴식/쉬기로 나눴다. '선택지'와 '변주'는 장소, 시간대, 장면으로 바꿨다.
- **시간대는 실제 시각을 따른다.** 해가 뜨고 지는 변화를 준다. 우선순위는 가장 낮아서 출시 후 첫 업데이트(M7)로 미룬다.

## 1. 한 줄 정의

공부하거나 일하는 동안, 내가 고른 아름다운 3D 장소에서 내가 고른 작은 캐릭터가 옆에서 함께 시간을 보내 주는 모바일·태블릿 앱.

## 2. 배경

- 자연의 풍경과 소리는 마음을 편하게 한다. (Calm을 쓰며 얻은 경험)
- **[가설]** 혼자 공부할 때 누군가 조용히 같이 있어 주면 자리를 지키기 쉽다.
- 기존 집중 앱은 타이머를 누르게 하거나, 카메라로 감시하고 교정하고 경쟁시킨다. 편안함과 동행을 함께 주는 제품은 드물다.

## 3. 제품 원칙

기능을 넣을지 말지 헷갈릴 때 이 여섯 가지로 판단한다.

1. **풍경이 본체다.** 가장 공들이는 것은 장면의 아름다움이고, 기능은 그 위에 얹는다.
2. **카메라는 심판이 아니라 동료의 눈이다.** 감지 결과로 지적하거나 벌주지 않는다.
3. **몰입을 깨지 않는다.** 알릴 일이 있으면 캐릭터의 행동이 먼저, 문구는 작게.
4. **점수가 아니라 함께한 시간이다.** 평가·비교·보상·경쟁을 넣지 않는다.
5. **영상은 기기 밖으로 나가지 않는다.**
6. **어느 기기에서나 같은 장면이다.** 화면 크기와 방향이 달라도 같은 장소, 같은 캐릭터, 같은 움직임을 보여 준다.

## 4. 사용자, 기기, 출시

- **사용자**: 혼자 공부하거나 일하는 사람. 출시 전까지는 만든 사람 본인이 매일 쓰며 검증한다.
- **기기**: 아이폰, 아이패드, 안드로이드 폰, 안드로이드 태블릿. 책상 위에 세워 둔 상태.
- **화면 방향**: 가로와 세로 모두 지원한다. 가로를 기본으로 권한다.
- **지원 하한**: 2022년 이후 출시 기기, 각 OS의 최신 두 개 버전. 그보다 오래된 기기에서도 실행은 막지 않는다. 프레임이 기준보다 낮게 나오면 "이 기기에서는 원활하지 않을 수 있어요"를 한 번만 보여 준다.
- **출시**: 앱스토어와 구글 플레이. 언어는 한국어와 영어. 일본어, 독일어 등은 출시 후 추가한다.

## 5. 시장 위치

2026년 11월 검색 기준이다. 같은 조합의 제품은 찾지 못했지만, 없다고 단정할 수는 없다. 출시 준비(M6) 때 다시 조사한다.

| 부류          | 예                                                | 방식                                          | 한계                                                                                              |
| ------------- | ------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 아늑한 동료형 | Spirit City: Lofi Sessions (Steam), gogh (iPhone) | 3D 공간과 캐릭터 + 타이머                     | 사용자가 시작 버튼을 누르는 타이머 기반. Spirit City는 모바일 버전이 없고 자원 사용량 불만이 있음 |
| 카메라 감지형 | 토마토마 (iPad), Timero, Paritose                 | 카메라로 자리·시선 감지, 자동 일시정지·재시작 | 감시·교정 톤. 토마토마는 집중 순간을 타임랩스로 저장하고 리그전으로 경쟁시킴                      |
| **이 앱**     |                                                   | 카메라 감지 + 장소·캐릭터·소리                | 감지 결과를 캐릭터의 행동으로만 표현. 영상 저장 없음, 경쟁 없음                                   |

토마토마는 감지가 어떻게 동작하는지 보는 데만 참고한다. 아이패드를 어디에 어떤 각도로 두는지, 고개를 숙이면 일시정지되는지, 다시 시작하기까지 얼마나 걸리는지를 직접 써 보며 기록한다. 타임랩스 저장과 리그전은 원칙 4·5에 어긋나므로 따르지 않는다.

## 6. 핵심 경험

1. 기기를 책상 위에 가로로 세우고 앱을 켠다. 지난번에 고른 장소와 캐릭터, 소리가 바로 시작된다.
2. 다른 장소나 캐릭터를 보고 싶으면 목록에서 고른다.
3. 내가 **착석**하면 캐릭터가 **집중 지점**에서 자기 일을 시작한다. (호수 장소에서는 데크 끝에서 낚시)
4. 잠깐 **이탈**하면 캐릭터는 하던 일을 멈추고 풍경을 보며 기다린다.
5. 오래 앉아 있으면 캐릭터가 먼저 일어나 기지개를 켜고, 작은 문구가 뜬다. "산책할 시간이에요. 산책하시겠어요?"
6. 끝내면 풍경 위에 요약 카드 한 장이 뜬다. "오늘 2시간 10분을 함께했어요."

## 7. 구조: 공통 로직과 콘텐츠

장소와 캐릭터를 계속 늘려 팔려면 앱을 세 부분으로 나눈다.

- **공통 로직**: 카메라 감지, 캐릭터 상태 전환, 휴식 제안, 세션 기록, 시간대 계산, 구매·다운로드, 설정. 한 번만 만든다.
- **장소**: 아래 장소 규격을 채운 콘텐츠 묶음. 장소를 추가할 때 공통 로직은 고치지 않는다.
- **캐릭터**: 아래 캐릭터 규격을 채운 콘텐츠 묶음. 캐릭터를 추가할 때 공통 로직과 장소는 고치지 않는다.

### 7.2 시간대 규격

시간대는 장소마다 새벽, 한낮, 해 질 녘, 밤 네 가지를 둔다. v1 출시 때는 한낮만 넣고, 나머지는 M7에서 추가한다.

| 항목      | 내용                                                         |
| --------- | ------------------------------------------------------------ |
| 구운 조명 | 시간대마다 Unity에서 구운 라이트맵 한 벌                     |
| 하늘과 물 | 하늘 색, 안개 색, 물 색                                      |
| 소리      | 레이어별 볼륨 (밤에는 새소리를 줄이고 장작 소리를 키우는 식) |

### 7.3 세 겹 영역과 화면 방향 (ADR 0001)

| 영역      | 범위             | 들어가는 것                                       |
| --------- | ---------------- | ------------------------------------------------- |
| 필수 영역 | 가로 4:3 안      | 집중 지점, 쉼 지점, 이동 경로, 캐릭터             |
| 핵심 구도 | 가로 4:3         | 필수 영역 + 장소를 대표하는 배경(산, 건너편 기슭) |
| 채움 영역 | 좌우로 2.2:1까지 | 하늘, 기슭, 앞쪽 땅                               |

- **가로 화면**: 화면비에 맞춰 화각을 자동으로 조정한다. 필수 영역은 항상 보인다. 화면이 넓으면 좌우 풍경이 더 보인다.
- **세로 화면**: **따라가기 시점**을 쓴다. 캐릭터를 중심에 두고 확대하며, 캐릭터가 걸어가면 천천히 따라 움직인다. **[가정]** 이 시점은 핵심 구도 밖으로 나가지 않는다.
- **가로 권유**: 세로로 시작한 세션마다 한 번, 화면 상단에 작은 팝업을 띄운다. "가로로 두면 풍경을 더 넓게 볼 수 있어요." 약 10초 뒤 사라진다. 버튼은 없다.

### 7.4 캐릭터 규격

| 항목       | 내용                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 모델       | 3D. 모든 캐릭터가 같은 사람형 뼈대를 쓴다                             |
| 다양성     | 얼굴, 머리, 옷, 체형, 소품으로 구분한다                               |
| 애니메이션 | 장소의 활동 애니메이션을 그대로 씌운다. 캐릭터별로 따로 만들지 않는다 |
| 썸네일     | 캐릭터 목록에 쓰는 이미지                                             |

- 사람형이 아닌 캐릭터(동물, 로봇 등)는 뼈대가 달라 v1에서 뺀다.
- 기본 캐릭터는 3명이다. 추가 캐릭터는 구매해야 고를 수 있다.

### 7.5 콘텐츠를 늘리는 방법

| 방법        | 새로 만드는 것                                                           | 비용    |
| ----------- | ------------------------------------------------------------------------ | ------- |
| 새 장소     | 모델, 텍스처, 세 겹 영역, 지점, 활동 애니메이션, 소리, 시간대 4개의 조명 | 가장 큼 |
| 새 캐릭터   | 모델과 텍스처. 애니메이션은 공유                                         | 중간    |

## 8. 기능 명세 (v1)

### 8.1 장소와 캐릭터 고르기

- 앱을 켜면 마지막으로 쓴 장소와 캐릭터로 바로 들어간다.
- 화면 가장자리의 작은 버튼으로 목록을 연다. 장소 목록에는 장소마다 썸네일을 한 장씩 둔다.
- 캐릭터는 한 번에 한 명만 나온다. 고른 캐릭터는 모든 장소에 따라간다.
- 세션 중에도 장소를 바꿀 수 있다. 화면이 천천히 어두워졌다가 밝아지고, 캐릭터는 새 장소의 같은 지점에서 같은 상태로 이어 간다. 세션도 하나로 이어지고, 쓴 장소는 모두 기록에 남는다.
- 구매하지 않은 장소와 캐릭터도 목록에 보이고, 고르면 구매 화면으로 간다.
- 캐릭터 꾸미기(옷, 색 바꾸기)는 없다.

### 8.2 첫 장소: 호수 데크

- **구도(가로 4:3)**: 뒤에서 앞으로 하늘 → 눈 덮인 산 → 건너편 기슭(침엽수, 텐트, 옅은 안개) → 호수 → 데크 → 앞쪽 기슭(텐트, 모닥불, 앙상한 나무).
- **배치**: 산은 가운데에서 약간 왼쪽. 데크는 오른쪽 아래 기슭에서 왼쪽으로 뻗는다. 모닥불과 텐트는 오른쪽 아래. 가로 화면이라 하늘보다 호수가 넓게 보인다.
- **데크**: 레퍼런스 사진보다 앞으로 당겨 배치한다.
- **채움 영역**: 좌우로 2.2:1까지 기슭과 호수를 이어 그린다.
- **스타일**: 양식화된 로우폴리 디오라마. 실사 재현이 아니다.
- **시간대**: v1 출시 때는 한낮. 새벽, 해 질 녘, 밤은 M7에서 추가한다.

| 움직이는 요소 | 움직임                        | 구현               |
| ------------- | ----------------------------- | ------------------ |
| 물            | 잔물결, 햇빛 반짝임           | 셰이더             |
| 구름          | 천천히 흐름                   | 평면 이동          |
| 나무·풀       | 바람에 흔들림                 | 버텍스 셰이더      |
| 모닥불        | 불꽃 깜빡임, 주변에 번지는 빛 | 셰이더 + 파티클    |
| 낚시찌        | 까딱임, 가끔 물결 고리        | 애니메이션         |
| 먼 연기, 새   | 가끔 등장                     | 파티클, 스프라이트 |

### 8.3 캐릭터 상태

- 풍경을 바라보는 뒷모습이 기본이다. 나와 같은 방향을 보는 동료가 되고, 지켜본다는 느낌이 없다.
- 내가 딴짓을 하거나 이탈해도 실망·재촉을 표현하지 않는다.

상태는 모든 장소와 캐릭터에 공통이고, 위치와 활동은 장소 규격에서 가져온다.

| 상태     | 조건                               | 캐릭터 행동                      | 위치      |
| -------- | ---------------------------------- | -------------------------------- | --------- |
| 함께하기 | 내가 착석해 있음                   | 집중 활동. 가끔 작은 동작을 섞음 | 집중 지점 |
| 기다리기 | 잠깐 이탈함                        | 하던 일을 멈추고 풍경을 바라봄   | 집중 지점 |
| 쉬기     | 휴식 제안을 수락했거나 오래 이탈함 | 쉬는 활동                        | 쉼 지점   |
| 돌아오기 | 쉬기 중 내가 다시 착석함           | 집중 지점으로 걸어가 다시 시작   | 이동 경로 |

### 8.4 카메라 감지

- **입력**: 기기 전면 카메라.
- **v1 신호**: 사람이 프레임 안에 있는가(있음/없음).
- **감지 방식**: MediaPipe Unity 플러그인. 고개를 숙이면 얼굴 감지가 끊길 수 있으므로, M1에서 얼굴 감지와 포즈(상반신) 감지 중 하나를 고른다. 플러그인이 막히면 iOS Vision과 Android ML Kit 네이티브 플러그인으로 바꾼다.
- **이후 신호**: 고개 방향(숙임/정면). 휴식 제안의 타이밍을 잡는 데 쓴다.
- **하지 않는 것**: 책인지 폰인지 구분, 표정·감정 분석, 몰입도 점수.
- **감지 주기**: 초당 1회.
- **프라이버시**: 영상은 기기 안에서만 분석하고 저장·전송하지 않는다. 화면에 카메라 영상을 보여 주지 않는다.

판정 규칙은 초기값이고, 써 보며 조정한다.

| 감지 | 지속 시간 | 전환                            |
| ---- | --------- | ------------------------------- |
| 있음 | 10초      | 함께하기 (쉬기 중이면 돌아오기) |
| 없음 | 30초      | 기다리기                        |
| 없음 | 5분       | 쉬기                            |
| 없음 | 30분      | 세션 자동 종료                  |

### 8.5 카메라를 끈 모드

- 시작 버튼을 누르면 함께하기로 들어간다. 기다리기 상태는 쓰지 않는다.
- 휴식 제안은 연속 시간 기준으로 그대로 한다.
- 산책을 수락하면 쉬기로 가고, 5분이 지난 뒤 화면을 탭하면 돌아오기로 넘어간다.
- 세션은 "오늘은 여기까지" 버튼으로만 끝난다.

### 8.6 소리

- 장소마다 레이어를 최대 4개 가진다. 호수 장소는 데크 기둥에 찰랑이는 물, 바람, 먼 새소리, 장작.
- 레이어별 볼륨 조절과 전체 음소거. 볼륨 설정은 장소별로 기억한다.
- 화면과 맞물린다. 바람 소리가 커질 때 나무가 더 흔들리고, 캐릭터가 찌를 던질 때 작은 소리가 난다.
- 음원은 직접 녹음하거나 상업 이용 라이선스가 확인된 음원만 쓴다.

### 8.7 휴식 제안

- **연속 시간**이 기준 시간(**[가정]** 50분)을 넘으면 제안한다.
- 순서
  1. 캐릭터가 하던 일을 내려놓고 일어나 기지개를 켠다.
  2. 화면 아래에 작은 문구가 뜬다. "산책할 시간이에요. 산책하시겠어요?" [산책하기] [조금 더]
- [산책하기]를 누르면 쉬기 상태가 되고 캐릭터는 쉼 지점으로 간다. 이후 5분은 감지 결과와 상관없이 쉬기를 유지한다. 그 뒤 착석이 10초 이어지면 돌아오기로 넘어간다.
- [조금 더]를 누르면 **[가정]** 15분 뒤 다시 제안한다.
- 문구가 떠 있는 동안 이탈해서 30초 넘게 돌아오지 않으면 산책을 수락한 것으로 본다. 쉬기로 가고 연속 시간을 0으로 돌린다.
- 응답 없이 착석해 있으면 문구는 20초 뒤 사라진다. **[가정]** 이 경우 [조금 더]와 같이 15분 뒤 다시 제안한다. 소리·진동 알림은 없다.
- 고개 방향 감지가 들어가면, 기준 시간을 넘긴 뒤 내가 고개를 드는 틈에 제안하도록 바꾼다.

### 8.8 시간 계산과 세션

- **세션**: 첫 착석에 자동으로 시작한다. "오늘은 여기까지" 버튼을 누르거나 30분 연속 이탈하면 끝난다. 자동으로 끝난 세션의 요약은 다음에 앱을 켤 때 보여 준다.
- **함께한 시간**: 착석 시간에 보류 구간을 더한다. **보류 구간**(기다리기 동안의 시간)은 5분 안에 돌아오면 함께한 시간에 들어가고, 쉬기로 넘어가면 통째로 빠진다. 상태가 바뀐 기록만 저장해 두고 나중에 계산한다.
- **연속 시간**: 쉬기에 들어갈 때만 0이 된다. 기다리기로는 끊기지 않는다. 예: 45분 앉아 있다가 3분 비우고 돌아오면 5분 뒤에 휴식 제안이 온다.
- **하루**: 새벽 4시에 바뀐다. 밤늦게 공부한 시간은 전날에 들어간다.

### 8.9 기록과 요약 카드

- **기록 항목**: 시작·종료 시각, 함께한 시간, 가장 길게 이어진 시간, 쉼 횟수와 이유(제안 수락, 오래 이탈), 쓴 장소와 캐릭터.
- **요약 카드**: 풍경 위에 카드 한 장. 그 하루의 함께한 시간 합계와 쓴 장소만 보여 준다. 가장 길게 이어진 시간은 점수처럼 작동하므로 카드에 넣지 않는다. 평가·점수·비교 문구도 넣지 않는다.
- **저장**: 기기 내부. v1은 지난 기록 목록까지만 제공한다.

### 8.10 시간대 (M7)

- 실제 시각에 맞춰 이웃한 두 시간대의 라이트맵, 하늘·물 색, 소리 볼륨을 섞어 해가 천천히 뜨고 지게 한다.
- 일출·일몰 시각은 위치 권한 없이 기기의 시간대 설정과 날짜로 대략 계산한다.
- 설정에서 시간대 하나로 고정할 수 있다.

### 8.11 구매와 콘텐츠

- **가격 구조**: 무료로 받는다. 첫 장소와 기본 캐릭터 3명은 무료다. 추가 장소와 추가 캐릭터는 하나씩 일회 구매한다. 구독, 광고, 뽑기(랜덤)는 없다.
- **가격**: **[가정]** 미정. M6에서 정한다.
- **콘텐츠 전달**: 기본 콘텐츠는 앱에 넣는다. 추가 장소와 캐릭터는 구매한 뒤 내려받는다(Unity Addressables). 파일은 정적 저장소(CDN) 한 곳에 둔다. 이 앱의 서버는 이것 하나뿐이다.
- **구매 복원**: 계정 없이 스토어의 구매 복원만 쓴다(Unity IAP). iOS는 설정에 "구매 복원" 버튼을 두고, 안드로이드는 자동으로 복원한다.
- **영수증 검증**: v1은 기기 안에서만 한다.

### 8.12 설정

장소·캐릭터 선택, 소리 레이어 볼륨, 휴식 제안 기준 시간과 끄기, 카메라 켜기·끄기, 화면 밝기 낮춤, 구매 복원, 언어, 시간대 고정(M7).

### 8.13 출시 준비 (M6)

- **[가정]** 첫 실행 안내: 기기를 세우는 위치와 카메라를 쓰는 이유를 한두 화면으로 알린다.
- **[가정]** 카메라 권한 안내 문구: "자리에 있는지만 확인하고, 영상은 저장하거나 보내지 않아요."
- **[가정]** 스토어 부제(30자 이내): 한국어 "곁에서 함께 공부하는 풍경", 영어 "Calm company while you study".
- **[가정]** 개인정보 처리방침: 영상 미저장·미전송, 계정 없음, 위치 미수집, 기록은 기기 안에만 저장.
- 화면 문구는 처음부터 언어 파일로 빼 둔다.

- 할 일 목록, 포모도로 타이머
- 캐릭터 꾸미기, 캐릭터와의 대화
- 사람형이 아닌 캐릭터

- 서버 영수증 검증
- 위치 권한, 실제 날씨와 연동되는 변화
- 2022년 이전 기기 최적화
- 한국어·영어 외 언어

## 10. 기술 방향 (ADR 0002)

- **엔진**: Unity 6 + URP 한 벌로 iOS와 안드로이드를 함께 만든다. UI도 Unity 안에서 만든다.
- **장면 제작**: Blender에서 모델링과 텍스처 → Unity로 가져와 조명 굽기. 물·불·풀처럼 움직이는 것만 셰이더로 얹는다.
- **콘텐츠 묶음**: 장소와 캐릭터를 각각 Addressables 묶음으로 만든다. 고른 것만 불러온다.
- **감지**: MediaPipe Unity 플러그인. 대안은 iOS Vision, Android ML Kit.
- **화면 꺼짐 방지**: 세션 중에는 기기 화면이 꺼지지 않게 한다.
- **성능 목표(초기값)**: 렌더 30fps 제한, 감지 1fps, 실시간 조명 없음, 2시간 연속 사용 시 과열 없음. 테스트 기기 네 종류 모두에서 지킨다.
- **비용**: Unity Personal(매출·투자 연 20만 달러 미만 무료) 조건 안에서 시작한다.

## 11. 마일스톤

일정 대신 각 단계가 답해야 할 질문을 적었다. 답이 "아니오"면 다음 단계로 가지 않는다.

| 단계 | 만드는 것                                                                                                              | 답해야 할 질문                                                           |
| ---- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| M0   | 레퍼런스와 팔레트 정리, Unity·C# 기초 익히기                                                                           | 분위기를 한 장으로 말할 수 있는가                                        |
| M1   | 회색 블록 호수 + MediaPipe 감지 + 화면 꺼짐 방지. 아이폰, 아이패드, 안드로이드 폰, 안드로이드 탭에서 가로·세로로 2시간 | 고개를 숙여도 감지가 유지되는가, 네 기기 모두 과열 없이 30fps가 나오는가 |
| M2   | 호수 장소 완성(한낮). 세 겹 영역, 물 셰이더, 움직이는 요소                                                             | 캐릭터 없이도 모든 기기에서 계속 보고 싶은 풍경인가                      |
| M3   | 캐릭터 1명 + 상태 4개 + 소리 4겹 + 세로 따라가기 시점                                                                  | 켜 두고 공부할 때 편안한가                                               |
| M4   | 감지 연동 + 휴식 제안 + 세션·요약 카드                                                                                 | 본인 기준(12장)을 통과하는가                                             |
| M5   | 기본 캐릭터 3명 + 두 번째 장소 + 장소·캐릭터 선택 화면                                                                 | 공통 로직을 고치지 않고 추가할 수 있는가                                 |
| M6   | 구매, 다운로드, 복원 + 한국어·영어 + 출시 준비 + 지인 5명 1주                                                          | 출시 전 기준(12장)을 통과하는가                                          |
| M7   | 실제 시각에 따른 시간대 변화(출시 후 첫 업데이트)                                                                      | 해가 지는 변화가 몰입을 깨지 않는가                                      |

- M0~M1에는 4주를 둔다. 4주 안에 회색 장면이 네 기기에 뜨고 감지가 돌아가면 계속한다. 넘기면 그때까지 실제로 쓴 주당 시간을 보고 범위를 다시 정한다.
- 장소 규격과 캐릭터 규격은 M1부터 지키되, 규격이 실제로 맞는지는 M5에서 검증한다.

## 12. 성공 기준

**본인 기준 (M4)**

- 2주 동안 공부한 날을 달력에 직접 표시하고 앱의 세션 기록과 비교한다. 공부한 날의 90% 이상에 세션이 있으면 통과.
- 켜 둔 채로 2시간 이상, 네 기기 모두 과열 없이 버틴다.

**출시 전 기준 (M6)**

- 아이폰, 안드로이드, 태블릿 사용자를 섞어 지인 5명이 1주 동안 쓴다. 3명 이상이 스스로 계속 켜고, 기기 때문에 생긴 문제가 없으면 통과.
- 다른 사람에게 보여 줬을 때 "예쁘다"는 반응이 먼저 나온다.

**구조 기준 (M5)**

- 두 번째 장소와 추가 캐릭터를 넣을 때 공통 로직 수정이 없다.
