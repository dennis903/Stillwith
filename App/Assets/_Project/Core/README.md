# Core — 공통 로직

기획서 7장의 "공통 로직". 한 번만 만들고, 장소나 캐릭터를 추가할 때 고치지 않는다.

- 어셈블리: `StudyMate.Core` (네임스페이스도 같음). `StudyMate`는 코드 안에서만 쓰는 이름이라 앱 이름이 바뀌어도 그대로 둔다.
- 들어갈 것: 카메라 감지, 캐릭터 상태 전환, 휴식 제안, 세션·시간 계산, 화면비별 화각(세 겹 영역), 소리 레이어, 설정, 구매·다운로드.
- **규칙**: Core는 특정 장소·캐릭터의 이름이나 에셋을 코드로 참조하지 않는다. 장소와 캐릭터는 Core가 정의한 데이터 형식(ScriptableObject)을 채워서 Core에 넘긴다.
- 어셈블리가 나뉘어 있어서, Core 밖(Assembly-CSharp)에 만든 스크립트는 Core에서 부를 수 없다. 이 제약이 규칙을 지켜 준다.
